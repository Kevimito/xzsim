# xzsim

xzsim es una app web de simulación 2D de flujo en yacimientos sobre una sección vertical XZ (similar a Petrel/INTERSECT), con pozos, zonas, tipos de roca y permeabilidades relativas.

## Conceptos principales

- **Sección XZ:** el modelo es un corte vertical 2D del yacimiento (X horizontal, Z profundidad).
- **Pozos:** pozos que atraviesan la sección.
- **Zonas:** división del modelo en zonas o capas.
- **Tipos de roca:** propiedades asignadas por tipo de roca.
- **Permeabilidades relativas:** curvas de permeabilidad relativa asociadas a cada tipo de roca.

## Datos

Los datos pesados (`.las`, `.segy`/`.sgy`, `.csv`, `.xlsx` y la carpeta `data/`) se guardan en el NAS y no se versionan en este repositorio.
